# BioBuzz FTC — робот-стрелок

Код под FTC SDK **12.0** (проверен компиляцией с SDK 12.0.0). Скопируйте `TeamCode/` в проект
[FtcRobotController](https://github.com/FIRST-Tech-Challenge/FtcRobotController).

## Конфигурация Driver Hub
| Имя | Устройство |
|---|---|
| `fl` `fr` `bl` `br` | моторы mecanum (goBILDA 312 rpm) |
| `intake` | мотор интейка |
| `shooterL` `shooterR` | моторы маховика (goBILDA 6000 rpm) |
| `hood` | серво капюшона (угол вылета) |
| `kicker` | серво толкателя (подаёт шар в маховик) |
| `imu` | IMU Control Hub |
| `Webcam 1` | USB-вебкамера (смотрит по оси маховика) |

7 моторов и 2 серво — в пределах лимита 8 + 8 (R501).

## Как работает точность
1. Камера видит группу AprilTag под ячейкой HIVE своего альянса (официальная библиотека SDK `getBioBuzzTagLibrary()`).
2. Робот сам поворачивается на цель; допуск по углу считается от ширины ячейки и дистанции.
3. Обороты маховика и капюшон берутся из **таблицы по дистанции** (`Shooter.java`).
4. Выстрел — только когда одновременно: навёлся, дистанция в рабочем диапазоне, робот стоит,
   оба мотора маховика в пределах ±2.5% от цели, и всё это держится 100 мс.

**Главное: заполнить таблицу в `Shooter.java` через OpMode `Shooter Tuner`.** Значения там сейчас примерные.

## Управление (TeleOp)
- **Gamepad1:** левый стик — езда, правый — поворот, RT — медленно.
  **RB** — автонаведение + автовыстрел. **LB** — то же + сам подъезжает на дистанцию.
  BACK — field/robot-centric, START — сброс IMU.
- **Gamepad2:** RT/LT — интейк, X — ручной выстрел, Y — предраскрутка, B — стоп маховика,
  D-pad ↑/↓ — поправка оборотов ±50, A — запасной выстрел без камеры (54").
- В init: X — синий альянс, B — красный.

## Автономка (30 с)
LEAVE → наведение и 4 выстрела → сбор и ещё выстрелы, если есть время → PARK в LOADING ZONE.
В init: X/B — альянс, D-pad ←/→ — старт у зрителей / дальний. Маршрут (`MainAuto.java`)
— заготовка, промерьте на своём поле. Для синих маршрут зеркалится.

## Правила, которые учтены
- G304: старт у стены, на своей половине, ровно 4 POLLEN.
- G402: в AUTO не заезжать на чужую половину — короткий маршрут.
- G403/G404: в конце AUTO все моторы останавливаются.
- G407: не больше 4 элементов сразу — **ограничьте это механически** (бункер на 4 шара).
- G417: в HIVE только запуском в ячейку, смотрящую вверх; не таранить HIVE.
- R702/R707/R708: обычная USB-вебкамера, без стерео.
