# 🐝 BioBuzz Shooter — код FTC-робота-стрелка

Робот для сезона **FIRST Tech Challenge 2026–2027 BIOBUZZ**. Он сам находит HIVE по AprilTag, наводится,
подбирает обороты маховика под дистанцию и стреляет POLLEN **только когда выстрел точно попадёт**.
В автономке робот всё делает сам, в TeleOp помогает водителю.

> Код собран под **FTC SDK 12.0** и проверен компиляцией против SDK 12.0.0.
> На реальном роботе его нужно откалибровать (см. «Первый запуск»).

## Что умеет

| | |
|---|---|
| 🎯 **Автонаведение** | Камера видит группу AprilTag под ячейкой HIVE своего альянса, робот поворачивается на цель |
| 🧭 **Без раскачки** | Угол с камеры переводится в курс с учётом задержки кадра, дальше робот держит курс по одометрии |
| 📏 **Обороты по дистанции** | Таблица «дистанция → RPM + капюшон» с интерполяцией |
| 🔋 **Компенсация батареи** | Feedforward маховика подстраивается под напряжение, обороты не плывут к концу матча |
| ✅ **Выстрел только при готовности** | Навёлся, не крутится, стоит на месте, дистанция в норме, маховик ±2.5%, шар на месте |
| 🔢 **Подсчёт реальных выстрелов** | Вылет шара определяется по просадке оборотов маховика, пустые толчки не засчитываются |
| 🚗 **Сам ездит** | Одометрия (goBILDA Pinpoint или энкодеры + IMU) и езда к точкам |
| 🅿️ **Автопарковка в TeleOp** | По кнопке: к сохранённой точке выстрела или в LOADING ZONE |
| 🛑 **Лимит 4 шара (G407)** | С датчиком бункера интейк сам не берёт пятый шар |
| 📳 **Подсказки водителю** | Цвет подсветки геймпада = готовность; вибрация на ENDGAME и на «пора парковаться» |
| ⚡ **Быстрый цикл** | Bulk-чтение хабов: все датчики за один запрос |

## Железо и конфигурация

Имена в конфигурации Driver Hub (их можно поменять в `Config.java`):

| Имя | Устройство | Обязательно |
|---|---|:-:|
| `fl` `fr` `bl` `br` | моторы mecanum (goBILDA 312 rpm) | ✅ |
| `intake` | мотор интейка | ✅ |
| `shooterL` `shooterR` | моторы маховика (goBILDA 6000 rpm, 1:1) | ✅ |
| `hood` | серво капюшона (угол вылета) | ✅ |
| `kicker` | серво толкателя (подаёт шар в маховик) | ✅ |
| `Webcam 1` | USB-вебкамера, смотрит по оси маховика | ✅ |
| `imu` | IMU Control Hub (нужен, если нет Pinpoint) | ⚠️ |
| `pinpoint` | goBILDA Pinpoint, I2C | ➕ рекомендуется |
| `loadedSensor` | датчик расстояния у толкателя («шар готов») | ➕ |
| `fullSensor` | датчик расстояния на месте 4-го шара («бункер полон») | ➕ |

**Итого: 7 моторов и 2 серво** при лимите 8 + 8 (R501). Необязательные устройства код находит сам:
если их нет в конфигурации, он просто работает без них.

## Установка

1. Скачайте [FtcRobotController](https://github.com/FIRST-Tech-Challenge/FtcRobotController) версии **12.0** или новее.
2. Скопируйте папку `TeamCode/src/main/java/org/firstinspires/ftc/teamcode/` из этого репозитория в свой проект.
3. Откройте проект в Android Studio и запустите сборку на Control Hub.
4. Создайте на Driver Hub конфигурацию с именами из таблицы выше.

## Первый запуск: чек-лист

Делайте по порядку, робот стоит на подставке или на поле:

- [ ] **Направления колёс.** В TeleOp стик вперёд — все 4 колеса крутятся вперёд. Если нет — поменяйте `REVERSE` в `Robot.java`.
- [ ] **Направление маховика.** Оба мотора крутят шар наружу. Если нет — поменяйте `REVERSE` в `Shooter.java`.
- [ ] **Толкатель.** Подберите `KICK_REST` и `KICK_FIRE`: в покое не мешает шару, при толчке подаёт его в маховик.
- [ ] **Одометрия.** В телеметрии `Позиция`: проедьте 24" вперёд — x ≈ 24; вбок влево — y растёт; поворот влево — угол растёт.
  - С Pinpoint: подберите `PINPOINT_X/Y_OFFSET_MM` и `PINPOINT_*_REVERSED`.
  - Без Pinpoint: проверьте `HUB_LOGO` / `HUB_USB` и подберите `STRAFE_MULT`.
- [ ] **Камера.** В init встаньте перед HIVE: в строке `Цель` должно появиться `RED …` / `BLUE …` с дистанцией. Сверьте её с рулеткой.
- [ ] **Маховик.** В Shooter Tuner поставьте 3000 RPM: L и R должны держать 3000 ± 75. Если медленно разгоняется — увеличьте `FLY_P`.
- [ ] **Калибровка выстрела** — следующий раздел.
- [ ] **Маршрут автономки** — промерьте точки в `Config.java` на своём поле.

## Калибровка выстрела

Это **главное для точности**. Числа в таблице сейчас примерные.

1. Запустите OpMode **Shooter Tuner**, в init выберите альянс (X/B).
2. Поставьте робота на ~30" от HIVE. Зажмите **LB**, робот наведётся.
3. **D-pad ↑/↓** меняет RPM, **→/←** меняет капюшон, **A** стреляет.
4. Добейтесь **5 попаданий из 5 в центр** ячейки.
5. Перепишите строку `СТРОКА ТАБЛИЦЫ: DIST … RPM … HOOD …` в `Config.java` → `DIST_IN`, `RPM`, `HOOD_POS`.
6. Повторите для 6–7 дистанций до 100". Дистанции в таблице должны идти по возрастанию.

**Советы**
- Калибруйте на заряженной батарее (≈ 12.5 В), под неё подобран `NOMINAL_VOLTAGE`.
- Если все шары уходят в одну сторону — подстройте `AIM_OFFSET_DEG`.
- Если на соревнованиях стрельба чуть сместилась (износ шаров, другое поле) — оператор поправляет обороты D-pad ↑/↓ на Gamepad2, таблицу трогать не надо.

## Управление

### Gamepad1 — водитель
| Кнопка | Действие |
|---|---|
| Левый стик | Езда |
| Правый стик X | Поворот |
| RT | Медленный режим |
| **RB** (держать) | **Автонаведение + автовыстрел** |
| **LB** (держать) | То же + сам подъезжает на рабочую дистанцию |
| **Y** (держать) | Автоезда к сохранённой точке выстрела |
| D-pad ← | Сохранить текущее место как точку выстрела |
| **A** (держать) | Автопарковка в LOADING ZONE |
| BACK | Переключить field-centric / robot-centric |
| START | Обнулить курс (робот смотрит от водителя) |

### Gamepad2 — оператор
| Кнопка | Действие |
|---|---|
| RT / LT | Интейк внутрь / наружу |
| X | Ручной выстрел |
| Y | Предраскрутка маховика вкл/выкл |
| B | Остановить маховик |
| A (держать) | Запасной выстрел без камеры (настроен на 54") |
| D-pad ↑ / ↓ | Поправка оборотов ±50 RPM |

### Подсказки
| Сигнал | Значение |
|---|---|
| 🟢 подсветка Gamepad1 | Огонь — всё готово |
| 🟡 | Наводится |
| 🔴 (при RB/LB) | Цели не видно |
| 📳 короткая | Бункер полон (4 шара) |
| 📳 двойная | 60 с до конца — ENDGAME |
| 📳 длинная | 15 с — пора парковаться |

## Автономка

**OpMode `BioBuzz Auto`** (после неё автоматически выбирается TeleOp, положение робота переносится).

**В init:** X — синий / B — красный, D-pad ← / → — старт у зрителей / дальний.
Робот перед стартом: касается стены, на своей половине, не в LOADING ZONE, ровно 4 POLLEN (G304).

| Время | Что делает |
|---|---|
| 0–2 с | Съезжает со стены на точку выстрела → **LEAVE (3)** |
| до 12 с | Наводится и стреляет, пока не вылетят 4 шара |
| если < 14 с | Собирает POLLEN и стреляет снова (до 24 с) |
| конец | Паркуется в LOADING ZONE → **PARK (5)**, полностью останавливается |

Точки маршрута лежат в `Config.java` (`SHOOT_NEAR`, `SHOOT_FAR`, `COLLECT_*`, `PARK`).
Они **для красных** в системе «старт = (0, 0, 0°), x вперёд, y влево», для синих зеркалятся сами.
**Промерьте их на своём поле** — сейчас это заготовка.

## Как устроена точность

```
Камера ──► группа AprilTag (до 16 углов) ──► дистанция + угол на цель
                                                  │
         курс робота в момент снимка ◄────────────┤  (история курса, учёт задержки)
                                                  ▼
                                   абсолютный курс на цель
                                                  │
         одометрия 100+ Гц ──► PD-регулятор курса ─┴─► поворот без раскачки
                                                  │
         таблица(дистанция) ──► RPM + капюшон ─────┤
         напряжение батареи ──► поправка F ────────┤
                                                  ▼
   ВЫСТРЕЛ только если ВСЁ сразу (и держится 80 мс):
     ✔ ошибка курса < допуска (центральные 40% ячейки)
     ✔ робот почти не вращается (< 15°/с) и стоит на месте
     ✔ дистанция 30–100"
     ✔ оба мотора маховика ±2.5% от цели
     ✔ шар у толкателя (если есть датчик)
                                                  ▼
   Просадка оборотов > 4% за 300 мс ──► выстрел подтверждён
```

## Настройки (Config.java)

Все числа — в **одном файле** `Config.java`, по разделам:

| Раздел | Что настраивать |
|---|---|
| Имена устройств | Если на Driver Hub другие имена |
| Шасси | Мотор/колёса, `STRAFE_MULT`, ориентация хаба |
| Pinpoint | Смещения ног, тип ног, направления |
| Езда к точке | `DRIVE_KP`, `HEADING_KP`, допуски |
| Автонаведение | `AIM_KP/KD/KS`, `AIM_OFFSET_DEG`, рабочие дистанции |
| Маховик | **Таблица выстрела**, PIDF, допуск скорости, просадка выстрела |
| Толкатель | Позиции и время |
| Датчики бункера | Пороги в см |
| Камера | Какую ячейку выбирать (`TARGET`), сглаживание, decimation |
| Маршрут AUTO | Точки и дедлайны |

## Правила BIOBUZZ, которые учтены

| Правило | Как соблюдается |
|---|---|
| **R501** — ≤ 8 моторов, ≤ 8 серво | 7 моторов, 2 серво |
| **R702 / R707 / R708** — камера | Обычная USB-вебкамера, без стерео |
| **G304** — старт | Подсказка в init: стена, своя половина, 4 POLLEN |
| **G402** — не мешать чужой AUTO | Короткий маршрут на своей половине |
| **G403 / G404** — стоять после AUTO и матча | `stopAll()` и ожидание до конца периода |
| **G407** — ≤ 4 элемента | С `fullSensor` интейк сам не берёт 5-й; **ограничьте бункер механически** |
| **G417** — HIVE только запуском | Робот стреляет и не таранит HIVE; стрельба только при наведении |
| **G410** — NECTAR во FLOWER в последние 60 с | Вибрация-напоминание на ENDGAME |

⚠️ **Проверьте сами:**
- Правила обновляются каждую неделю — сверяйтесь с актуальным [Competition Manual](https://first-resources.pdx-prod.ftclive.org/ftc/game/cm-html) и Q&A.
- HIVE наклоняется. Убедитесь на поле, какая группа меток видна с вашей точки выстрела, и при необходимости поменяйте `Config.TARGET`.

## Структура кода

```
teamcode/
├── Config.java            ← все настройки
├── Robot.java             ← железо, цикл update(), езда, наведение, телеметрия
├── Shooter.java           ← маховик, капюшон, толкатель, датчики бункера, подсчёт выстрелов
├── Vision.java            ← камера + AprilTag-группы HIVE (библиотека SDK BioBuzz)
├── Localizer.java         ← интерфейс одометрии
├── PinpointLocalizer.java ← goBILDA Pinpoint
├── WheelLocalizer.java    ← энкодеры колёс + IMU (запасной)
├── Pose.java              ← x, y, курс; зеркалирование для синих
├── MainTeleOp.java        ← «BioBuzz TeleOp»
├── MainAuto.java          ← «BioBuzz Auto»
└── ShooterTuner.java      ← «Shooter Tuner», калибровка таблицы
```

**Главное правило:** в каждом цикле сначала `robot.update()`, потом всё остальное.

## Если что-то не так

| Проблема | Что проверить |
|---|---|
| `Цель: не видно` | Альянс выбран верно? Камера `Webcam 1` в конфиге? Свет, фокус, `DECIMATION = 1` для дальних дистанций |
| Робот раскачивается при наведении | Уменьшите `AIM_KP`, увеличьте `AIM_KD` |
| Не доворачивает последние градусы | Увеличьте `AIM_KS` |
| Наводится, но не стреляет | Посмотрите телеметрию: маховик на скорости? шар готов? дистанция 30–100"? |
| Шары стабильно в одну сторону | `AIM_OFFSET_DEG` |
| Перелёт/недолёт | Таблица выстрела или поправка RPM на Gamepad2 |
| Выстрелы не считаются | Уменьшите `SHOT_DROP` (например 0.03) |
| Автономка промахивается мимо точек | Проверьте одометрию (чек-лист), потом `DRIVE_KP` / `DRIVE_KS` |
| Pinpoint `FAULT_*` | Проверьте провода ног и `PINPOINT_*_REVERSED` |
| Медленный цикл (> 30 мс) | Камера: `DECIMATION = 3`; не добавляйте `sleep()` в цикл |
